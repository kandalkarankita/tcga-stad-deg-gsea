# TCGA-STAD genomics demonstration

Differential expression (DESeq2), GSEA and GO/KEGG enrichment on TCGA-STAD
(60 primary tumors, 36 normals), following the workflow of Jiang et al. 2023,
Cell Reports Medicine, Figure 7. Tumor vs. normal is used as a stand-in for DLRS.

- TCGA_STAD_DEG_GSEA.ipynb : full notebook with code, QC, results and interpretation
- TCGA_STAD_DEG_GSEA.html  : rendered report (download to view)
- figures/                 : all plots and result tables

Runs in Google Colab with the R runtime.
